# Linux Command Line
## Concepts Learned 
- Investigating your computer system
- Checking Disk and Storage infomation
- Reading a System File
## Commands Practised 
 - `whoami`
 - `uname -a` 
 - `uname` 
 - `df -h`
 - `ls -l`
 -  `cd`
 - `cd ..`
 - `pwd` 
 - `ls`
 - `ls -al`
 - `find ~ -name <filename>` 
 - `cat`

## Key Commands I learned
   ### `whoami`
   Shows the current user logged into the system.

   ### `pwd` 
   Displays the current working directory.

   ### `find`
   Used to search for files and directories.

   ### `cat`
   Used to read content inside a file.

   ### `ls`
   Lists all files and folders of the current directory.

## Key Takeaways 
- Linux is easy to use and the CLI is indeed preferable than the GUI.
- I learned how to examine system information.
- I learned how to search for files.
- I learned how to navigate directories.
