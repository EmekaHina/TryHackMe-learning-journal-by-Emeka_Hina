# Windows Command Line
## Concepts learned 
- Navigating directories
- Accessing hidden files
- File reading

## Commands learned
- `dir`
- `dir /a`
- `dir /s`
- `type`
- `systeminfo`
- `hostname`
- `cd`
- `cd ..`

## Key Commands I learned:
 ### `hostname` 
  Shows the name the user is logged in as.

 ### `dir`
  List the contents of the current directory.

 ### `cd`
  Shows current directory.

 ### `systeminfo`
 Shows information about the Operating System.

 ### `dir /s`
 Used to find a file on the disk.
